# Intake Golden Data

This folder stores the 3 reference intake scenarios we aligned on during prompt
design.

- `scenario_1_vague_new_request.md`
- `scenario_2_unrealistic_scope_or_capacity.md`
- `scenario_3_existing_draft_update.md`

These are not runtime fixtures. They are human-readable golden references for
how the Intake agent should think, pace questions, use tools, and move toward
`commit_intake`.
